# SeeAI Visual System — Approved Direction

## Positioning

SeeAI should feel like a **technical learning product**, not a generic AI startup landing page.

The target feeling is:

- clear
- calm
- precise
- modern
- engineering-oriented
- trustworthy

## Core palette

```text
Background       #FBFBF8
Surface          #FFFFFF
Graphite text    #17201E
Muted text       #65716C
Primary teal     #0F766E
Strong teal      #095E57
Soft teal        #EDF7F3
Border           #E2E7E3
```

## Rules

- No large blue-purple brand gradients.
- No neon glow as a default brand device.
- No fake futuristic neural-network decoration unless it explains a concept.
- Use accent colors semantically inside simulations, not as generic “AI magic”.
- Prefer white cards, thin borders, generous whitespace, and restrained shadows.
- Motion must explain state change.

## Brand idea

> Future technical textbook, not AI startup template.
